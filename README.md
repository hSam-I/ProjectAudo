# Project Audo

> AI-powered, multi-agent algorithmic trading framework.

## Vision

Project Audo is an open, modular and scalable algorithmic trading platform.

The goal is not to build a simple trading bot, but to create a professional framework that combines:

- Multi-Agent Analysis
- Machine Learning
- Quantitative Finance
- Backtesting
- Paper Trading
- Live Trading
